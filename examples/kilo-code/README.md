# Kilo Code with plugboard

A Kilo CLI provider block for plugboard's Chat Completions route. The client guide is [docs/clients/kilo-code.md](https://github.com/jjjermiah/opencode-plugboard/blob/main/docs/clients/kilo-code.md), which has the plugboard options (app `kilo-code`), the VS Code settings for all three provider API choices, and what is not confirmed.

- `kilo.json`: the provider block for the CLI. The file name and directory come from third-party Kilo guides, not Kilo's docs. Check them against your Kilo install. Export `PLUGBOARD_KEY_KILO_CODE` before you start.

Not run against plugboard yet.
