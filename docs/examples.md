# Examples

Each client has a runnable example in [`examples/`](https://github.com/jjjermiah/opencode-plugboard/tree/main/examples). A scripted run of every example is committed and checked in CI. A live run is against a real provider: its directory is named for the date and the plugboard commit, and it is never rewritten. A live directory with only a report is a historical record.

The table is built from the run records by the docs build. The same records make the generated index in [`examples/README.md`](https://github.com/jjjermiah/opencode-plugboard/blob/main/examples/README.md).
